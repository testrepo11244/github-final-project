# Contributing to github-final-project

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

This project is a simple interest calculator written as a Bash script. Contributions that keep the calculator clear, correct, and easy to run are especially helpful.

## How to contribute

1. Fork the `github-final-project` repository.
2. Create a branch for your change.
3. Make your update to the script, docs, or related files.
4. Test `simple-interest.sh` with sample principal, rate of interest, and time period values.
5. Open a pull request and describe what you changed.

## What you can contribute

- Bug reports for incorrect simple interest results or input handling
- Bug fixes for calculation, validation, or script errors
- Documentation improvements for README and usage examples
- Enhancements such as clearer prompts or formatted output
- Ideas for making the calculator easier to use

Please be respectful in issues and pull requests, and follow `CODE_OF_CONDUCT.md`.
